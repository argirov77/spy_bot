# Telegram Spy Bot (one-phone / hot-seat)

## Запуск
1. Копирай `.env.example` в `.env`.
2. Попълни `BOT_TOKEN` и `API_SECRET`.
3. Стартирай:
   ```bash
   docker compose up --build
   ```

API автоматично чака Postgres и изпълнява `alembic upgrade head`.

## Работа в Telegram
- `/start` → главно меню.
- **Списъци** → **Добави списък**:
  - Изпрати име.
  - Изпрати думи/фрази (редове и/или запетаи).
  - Ботът връща: `Намерени / Добавени / Дубликати`.
- **Нова игра**:
  - Избор на списък.
  - Избор на preset (например 5/1) или ръчен формат `N S`.
  - Потвърждение и **Старт**.

## Игрови flow
- Един екран в групата се редактира динамично.
- Текущият играч: `Играч i от N`.
- Бутони според състоянието:
  - преди reveal: **Покажи / Статус / Край**
  - след reveal: **Скрий / Край**
  - след hide: **Следващ / Статус / Край**
- След последния играч: `Всички видяха ролята си. Започнете обсъждане.`
- **Край** показва думата и индексите на шпионите.
